Windows-first Kotlin Compose Desktop app for offline music playback. Repo has two main modules: shared-core for contracts/domain/state and desktop-app for Compose UI, JavaFX playback, parser integration, persistence, and packaging. Product focuses on real desktop MVP flows: local library scan, playlists, parser search/preview/download, and packaged Windows installer output. The OCR screenshot-import flow was removed deliberately; do not reintroduce it.
